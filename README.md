# ⁷zking.sensi — projeto Android

Este projeto transforma o gerador HTML em um aplicativo Android usando WebView.

## Como abrir
1. Instale o Android Studio em um computador.
2. Extraia este ZIP.
3. No Android Studio, escolha **Open** e selecione a pasta `7zking-sensi-android`.
4. Aguarde a sincronização do Gradle e instale os componentes do Android SDK 36, se solicitado.
5. Para testar no celular, conecte um Android com depuração USB ativada e pressione **Run**.

## Como gerar APK ou AAB
No Android Studio, abra **Build > Generate Signed Bundle / APK**.
- Escolha **APK** para gerar um arquivo de teste/instalação.
- Escolha **Android App Bundle (AAB)** para preparar o envio à Google Play.
Crie e guarde com segurança sua chave de assinatura. Não compartilhe o arquivo de chave nem as senhas.

## Configuração
- Nome: ⁷zking.sensi
- ID do aplicativo: `com.zking.sensi`
- Versão inicial: 1.0
- SDK alvo: 36 (Android 16)
- O app não solicita permissão de internet.

Este ZIP contém o projeto-fonte, não um APK/AAB já compilado. A publicação depende da compilação, assinatura, ficha da loja, política de privacidade quando aplicável e aprovação do Google Play.
